## EU Public Tenders & Contract Awards (TED) This Actor extracts open EU public tenders, prior information notices and contract awards from the official Tenders Electronic Daily (TED) database and returns structured procurement metadata (exportable as JSON, CSV or Excel) with English titles for every notice. It performs full-text keyword search across original notice languages, supports filtering by CPV codes, buyer country, estimated or awarded value and deadlines, and classifies notice type (open tender, prior information, contract award). Output includes multilingual titles, buyer and location details, CPV classifications, procurement procedure and timing information (deadlines and time-to-deadline), estimated or awarded values, lot structure, identification of award winners, and links to the official notice pages and English PDFs. The Actor uses the official TED Search API v3 as its data source and provides a scheduled monitor mode to run daily and return only newly seen notices. ## Use cases - Discover bid opportunities from EU public buyers (open tenders) - Identify upcoming procurement for early preparation (prior information notices) - Gather competitor intelligence and market sizing from contract awards - Continuous monitoring for new or changed notices via daily scheduled runs

Fonte dos dados: https://api.ted.europa.eu/v3/notices/search.
