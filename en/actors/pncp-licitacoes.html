Brazil open tenders (PNCP)

Open Brazilian tenders from PNCP, with alerts for new ones only.

Open on Apify Store
Coverage
Brazil, all levels of government
Price
US$2.00 per 1,000 results
Source
pncp.gov.br
Formats
JSON, CSV, Excel, API

Searches open calls on Brazil's national procurement portal (PNCP) by keyword, state, procurement method and value. In monitor mode each run returns only notices you haven't seen, optionally with line items and unit prices.

What you get

  • Title and description
  • Buyer, city and state
  • Procurement method
  • Estimated value
  • Bid deadline
  • Notice link

What it's for

  • Daily alert for tenders in your segment
  • Spreadsheet of calls with deadline and estimated value
  • Line items and unit prices to build a bid

Example input

{
  "keywords": [
    "notebook",
    "computador"
  ],
  "ufs": [
    "SP",
    "MG"
  ],
  "maxResults": 20,
  "includeDetails": true
}
